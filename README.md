# Mon Omra 🕋

Application Android hors ligne pour accompagner la Omra :

- Les 8 étapes : Ihram, interdits, entrée à la mosquée, Tawaf, Maqam Ibrahim, Zamzam, Sa'i, rasage ou raccourcissement
- Les invocations en arabe, phonétique et français
- Un compteur de tours de Tawaf (7) et de trajets de Sa'i (7, avec Safa ou Marwa), avec vibration
- La progression est enregistrée et l'écran reste allumé pendant les compteurs

Installer : ouvrir **Releases** depuis le téléphone et télécharger `MonOmra.apk`.

Ce guide résume les rites selon l'avis courant. En cas de doute, demandez à votre guide ou à un savant.
